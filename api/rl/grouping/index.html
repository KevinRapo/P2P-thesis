    grouping¶

    core.rl.grouping · source on GitHub

    How the paradigms see a multi-agent environment: grouped (CTCE) or with a central state (CTDE).

    GroupedEnv (CTCE): all agents as one agent, "group". It observes every agent's observation and outputs every agent's action, each joined into one flat Box in the environment's agent order, and receives the sum of the agents' rewards: one controller maximising the total (the social planner). RLlib's own modules and algorithms train it as an ordinary single agent.

    CentralStateEnv (CTDE): the agents stay separate, each with its own reward, but each agent's observation is extended with the global state, every agent's observation joined: [o_i, o_1, ..., o_N]. The CTDE modules (core/rl/ctde_modules.py) let the actor read only o_i and the critic read all of it, so the critic is central and the actor decentralised.

    Fixes I-59: the original put the agents' spaces in sorted name order and their data in environment order. Here both follow env.agents_id, and each agent keeps its own action bounds in its slice of the joint Box, so RLlib rescales every agent's action to that agent's bounds.

    The wrapped environment must have every agent act at every step (as the market does): agents_id, one Box per agent in observation_spaces and action_spaces, and "__all__" in terminateds and truncateds.

    The group's infos hold the agents' own rewards and infos ({"rewards": {...}, "infos": {...}}), so evaluation and the market's metrics can be read per agent as in DTDE.

    def step(
    self, action_dict: MultiAgentDict
) -> tuple[
    MultiAgentDict, MultiAgentDict, MultiAgentDict, MultiAgentDict, MultiAgentDict
]:
    actions = split(action_dict[GROUP], self.agents_id, self.act_dims)
    obs, rewards, terminateds, truncateds, infos = self.env.step(actions)
    missing = set(self.agents_id) - set(rewards)
    if missing:
        raise ValueError(
            f"GroupedEnv needs every agent at every step; no reward for {missing}."
        )
    group_reward = float(sum(rewards[a] for a in self.agents_id))
    return (
        {GROUP: join(obs, self.agents_id)},
        {GROUP: group_reward},
        {GROUP: terminateds["__all__"], "__all__": terminateds["__all__"]},
        {GROUP: truncateds["__all__"], "__all__": truncateds["__all__"]},
        {GROUP: {"rewards": dict(rewards), "infos": infos}},
    )

    def join_spaces(boxes: list[spaces.Box]) -> spaces.Box:
    """One ``Box`` holding the given boxes one after the other."""
    return spaces.Box(
        low=np.concatenate([b.low.reshape(-1) for b in boxes]),
        high=np.concatenate([b.high.reshape(-1) for b in boxes]),
        dtype=np.float32,
    )

    def split_space(box: spaces.Box, dims: list[int]) -> list[spaces.Box]:
    """Cut a joint ``Box`` back into one ``Box`` per agent."""
    edges = np.cumsum([0, *dims])
    return [
        spaces.Box(box.low[a:b], box.high[a:b], dtype=np.float32)
        for a, b in zip(edges[:-1], edges[1:])
    ]

    def split(joint: np.ndarray, agents: list[str], dims: list[int]) -> dict:
    """Cut a joint vector into each agent's part, in ``agents`` order."""
    edges = np.cumsum([0, *dims])
    return {
        agent: np.asarray(joint[..., a:b], dtype=np.float32)
        for agent, a, b in zip(agents, edges[:-1], edges[1:])
    }

    def join(values: dict, agents: list[str]) -> np.ndarray:
    """Join each agent's vector into one, in ``agents`` order."""
    return np.concatenate(
        [np.asarray(values[a], dtype=np.float32).reshape(-1) for a in agents]
    )

    def central_obs(obs: dict, agents: list[str]) -> dict[str, np.ndarray]:
    """Each agent's observation followed by every agent's, ``[o_i, o_1..o_N]``."""
    state = join(obs, agents)
    return {
        a: np.concatenate([np.asarray(obs[a], dtype=np.float32).reshape(-1), state])
        for a in agents
    }
