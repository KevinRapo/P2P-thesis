    toy¶

    core.rl.envs.toy · source on GitHub

    Small multi-agent environments with a known best return, for testing the RL code.

    They have the interface the trainer needs from the local energy market (core/rl/train.py), so the algorithms and training paradigms can be checked without it:

    • built as Env(env_config);
    • agents_id: the agents, in a fixed order;
    • observation_spaces and action_spaces: one Box per agent;
    • reset and step return one entry per agent, and "__all__" in terminateds and truncateds; an episode lasts max_steps steps.

    Two tasks, each with a known best and random return per agent and episode:

    • TargetEnv: each agent sees a private target and is paid for matching it. Rewards are individual, so every paradigm should learn it.
    • BalanceEnv: each agent sees its own net position and chooses a trade; all agents get the same team reward for the total imbalance. The best policy is still "trade your own position", but each agent's effect on its reward is mixed with everyone else's (credit assignment), which centralised training should handle better than independent learners.

    def baseline_return(
    env_class: type[_ToyEnv],
    env_config: dict[str, Any],
    policy: str,
    episodes: int = 200,
    seed: int = 0,
) -> float:
    """Mean episode return of all agents together (what RLlib reports as
    ``episode_return_mean``) under ``policy``: ``"best"``, ``"random"`` or
    ``"zero"`` (always act 0)."""
    env = env_class(env_config)
    rng = np.random.default_rng(seed)
    totals = []
    for episode in range(episodes):
        env.reset(seed=seed + episode)
        total, done = 0.0, False
        while not done:
            if policy == "best":
                actions = {a: env.best_action(a) for a in env.agents_id}
            elif policy == "random":
                actions = {
                    a: rng.uniform(-1, 1, env.act_dim).astype(np.float32)
                    for a in env.agents_id
                }
            elif policy == "zero":
                actions = {
                    a: np.zeros(env.act_dim, dtype=np.float32) for a in env.agents_id
                }
            else:
                raise ValueError(f"Unknown policy {policy!r}")
            _, rewards, terminateds, _, _ = env.step(actions)
            total += sum(rewards.values())
            done = terminateds["__all__"]
        totals.append(total)
    return float(np.mean(totals))
