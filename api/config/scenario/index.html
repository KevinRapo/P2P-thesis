    scenario¶

    core.config.scenario · source on GitHub

    The scenario: everything the user configures before stepping the market.

    Only what a market step without RL needs: the network, the participants on it, the market rules and the DSO. Plain data, edited by the Studio pages and read by the LocalEnergyMarket that runs the market on the network.

    Market rules ([P1] §3.3) and how participants bid.

    Attributes:

    Name Type Description
    mechanism str

    Pricing mechanism (core/market/clearing_price.py, [P1] §3.3.3).
    min_price float

    Lowest order price, p_min ([P1] eq. 2).
    max_price float

    Highest order price, p_max ([P1] eq. 2).
    min_quantity float

    Smallest order quantity (kWh), q_min ([P1] eq. 2).
    max_quantity float

    Largest order quantity (kWh), q_max ([P1] eq. 2).
    partner_preference bool

    Participants name a preferred partner β on the other side ([P1] eq. 2; stage 1 of the clearing, §3.3.2).
    partner_reputation_weight float

    How the partner is chosen ([P1] §3.4): weight of the candidate's reputation against its closeness on the grid (0: the nearest, 1: the most reputable).
    bid_margin float

    Where participants bid between the DSO's tariffs: sellers ask FiT + margin · spread, buyers bid utility − margin · spread. Below 0.5 bids and asks overlap and peers trade.
    bid_jitter float

    Random spread of the prices around that, as a share of the tariff spread, so the order book is not flat.
    seed int

    Seed of the jitter.
    ledger_difficulty int

    Proof-of-work difficulty of the trade ledger (0: off; [P1] §3.3.4).
    reliability_weight float

    w_rel of the reputation ([P1] eq. 12; not given in [P1], the original's value).
    fairness_weight float

    w_fair of the reputation ([P1] eq. 12).
    grid_weight float

    w_grid of the reputation ([P1] eq. 12).
    reputation_decay float

    Share of the old reputation kept per hour ([P1] §3.3.4 names a decay factor without a value). Applied per step as reputation_decay ** step_hours, so the memory lasts the same time with hourly and quarter-hourly steps (I-38b): 0.8 halves the old reputation in about 3.1 hours.

    def problems(self) -> list[str]:
    """What makes these rules wrong or the peer market pointless."""
    found = []
    if self.bid_margin >= 0.5:
        found.append(
            "Bid margin is 0.5 or more: peers will not trade with each other."
        )
    if self.min_price > self.max_price:
        found.append("Min price is above max price.")
    if self.min_quantity > self.max_quantity:
        found.append("Min quantity is above max quantity.")
    weights = (self.reliability_weight, self.fairness_weight, self.grid_weight)
    if any(w < 0 for w in weights) or abs(sum(weights) - 1) > 1e-9:
        found.append("Reputation weights are not shares that add up to 1.")
    for name in ("reputation_decay", "partner_reputation_weight"):
        if not 0 <= getattr(self, name) <= 1:
            found.append(f"{name.replace('_', ' ').capitalize()} is not in 0-1.")
    return found

    def problems(self) -> list[str]:
    """Tariffs that break p_FiT < p_P2P < p_utility ([P1] §3.3.2), so peers
    gain nothing by trading with each other, and fee settings out of range."""
    found = []
    if self.feed_in_tariff >= self.utility_price:
        found.append(
            "Feed-in tariff is not below the utility price: no gain from peers."
        )
    if not 0 <= self.fee_buyer_share <= 1:
        found.append("Fee buyer share is not in 0-1.")
    if not 0 <= self.thermal_threshold < 1:
        found.append("Thermal threshold is not in 0-1 (1 excluded).")
    return found

    def problems(self, element_types: Optional[Mapping[str, str]] = None) -> list[str]:
    """What would make the market pointless or wrong, in plain words.

    Args:
        element_types: Element type per network element (``load``, ``sgen``,
            ``storage``), to check that someone can generate and that taken
            over storage has a battery; skipped when ``None``.
    """
    found = []
    if not self.participants:
        found.append("No participants: place them on the Grid & Participants page.")
    elif element_types is not None and not any(
        element_types.get(e) == "sgen" for p in self.participants for e in p.owns
    ):
        found.append(
            "No participant owns a generator: nobody has anything to sell."
        )
    if element_types is not None:
        for p in self.participants:
            storage = [e for e in p.owns if element_types.get(e) == "storage"]
            if storage and p.battery is None:
                found.append(
                    f"{p.id} takes over {', '.join(storage)} but has no "
                    "battery: the storage unit would disappear."
                )
    return found + self.market.problems() + self.dso.problems()
