    contract¶

    core.grid.contract · source on GitHub

    Technology-neutral grid contract: what crosses the grid seam.

    Plain, frozen data only: no pandapower, SimBench or NetworkX objects cross this seam. The pandapower adapter (core/grid/simbench.py) produces these records; the market, the services and the Studio consume them.

    The catalog records are used by the Studio's Inspect page. ParticipantInjection and GridModel are the step-time contract and have no implementation yet.

    ProfileRecord dataclass ¶

    ProfileRecord(
    name: str,
    table: str,
    quantities: tuple[str, ...],
    elements: int,
    mean: float,
    peak: float,
)

    One SimBench profile of a network: a normalised yearly time series.

    Values are factors of an element's rated power (1.0 = rated power), one row per 15 minutes of the profile year.

    Attributes:

    Name Type Description
    name str

    Profile name, e.g. "H0-A" (household) or "PV5".
    table str

    SimBench profile table: "load", "renewables", "powerplants" or "storage".
    quantities tuple[str, ...]

    ("p",), or ("p", "q") for loads (active and reactive).
    elements int

    Number of network elements that use this profile.
    mean float

    Mean active-power factor over the year.
    peak float

    Highest active-power factor over the year.
