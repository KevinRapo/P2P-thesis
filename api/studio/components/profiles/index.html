    profiles¶

    studio.components.profiles · source on GitHub

    Overview of SimBench's profile classes, after SimBench's own figure.

    SimBench groups its time series into load (accumulated standard profiles and individual devices), generation, storage and aggregated grids (Meinecke et al., 2020, Figure 1). The overview draws these groups as panels with one tile per class and its number of profiles, so the catalogue is clustered before it is listed. Clicking a tile adds its class to the selection, clicking it again removes it; the table lists the profiles of all selected classes.

    def show(self, types: list[ProfileType]) -> None:
    """Draw the panels with the number of ``types`` in each class."""
    self.counts = Counter(t.category for t in types)
    self._draw()

    async def pick(self, key: str | None) -> None:
    """Toggle a class in the selection (``None``: clear it); explain the
    selection and tell the owner.
    """
    if key is None:
        self.picked.clear()
    else:
        self.picked ^= {key}
    self._draw()
    self._explain()
    await self.on_pick(set(self.picked))
