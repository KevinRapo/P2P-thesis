    market_service¶

    studio.adapters.market_service · source on GitHub

    MarketService: the market built from the scenario, stepped by the Step page.

    The only place that builds and holds the LocalEnergyMarket. The Studio asks it to build the market from the current scenario and to step it; pages read the manager's state (history, participants, pending step) to display it but never construct or drive it themselves. The records the manager returns are plain data.

    def build(self, scenario: Scenario) -> LocalEnergyMarket:
    """A fresh market from ``scenario`` (the manager copies it), reset to step 0."""
    manager = LocalEnergyMarket(scenario)
    manager.reset()
    self.manager = manager
    return manager

    def next_part(self) -> None:
    """The next part of the step: collect the orders when no step is running,
    else the next clearing stage, or settlement and the power flow."""
    m = self._built()
    if m.pending is None:
        m.start_step()
    else:
        m.advance()
