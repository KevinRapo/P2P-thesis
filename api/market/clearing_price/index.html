    clearing_price¶

    core.market.clearing_price · source on GitHub

    Clearing (pricing) mechanisms: the price of a matched buy and sell order.

    [P1] §3.3.3. Every mechanism takes the same three arguments, in the same order: the buy order, the sell order and a reference price (the previous clearing price, or the midpoint of the DSO's tariffs). The original code let each mechanism name its own arguments, so the seller mechanism received the buy order and returned the buyer's price; one fixed signature rules that out.

    def calculate_price(
    self, buy_order: Order, sell_order: Order, reference_price: float
) -> float:
    buyer = max(0.0, buy_order.price - reference_price)
    seller = max(0.0, reference_price - sell_order.price)
    spread = buy_order.price - sell_order.price
    if buyer + seller == 0 or spread <= 0:
        return (buy_order.price + sell_order.price) / 2
    return sell_order.price + buyer / (buyer + seller) * spread
